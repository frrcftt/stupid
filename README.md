# Maybe I'm Stupid ♡

A small expressive single-page website with drifting petals, floating hearts, and background music controls.

## Deploy

This repository includes a GitHub Actions workflow that deploys the site to GitHub Pages on pushes to `main`.

## Music

Place the supplied audio file at the repository root as `background-music.mp3`. The page references that filename. Browsers may block autoplay until a visitor taps **Play music**.

## Local preview

Open `index.html` in a modern browser. Keep `background-music.mp3` beside it.
